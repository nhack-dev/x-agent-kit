# x-agent-kit ── X（旧 Twitter）運用を AI エージェントにまかせるキット

あなたの AI エージェント（Claude Code など）にこのリポジトリを読ませると、X の運用担当として
**リサーチ → 企画 → 下書き → 投稿・予約 → 振り返り → 次の企画** を毎週まわしてくれます。

| できること | X API あり | X API なし |
|---|---|---|
| リサーチ（伸びている投稿・ジャンル・参考アカウントの型） | 検索・アカウントの投稿を読む → 型を数える | 画面で見た投稿を貼る → 型を数える |
| ツリー型ポスト | 下書き → 検査 → あなたの OK で投稿 | 下書き → 検査 → あなたが貼る |
| 単発ポスト | 同上 | 同上 |
| 引用・リプライ案 | 下書きを作る（引用は API では不可・返信は @ で呼ばれたときだけ API で送れる） | 下書き → あなたが貼る |
| 投稿予約 | 手元の予約表から時刻に投稿 | X の画面の予約にあなたが貼る |
| 数字の振り返り（表示・保存・プロフへのアクセス） | 自分の投稿の数字を読む → 表と次の企画の仮説 | 画面で見た数字を書く → 同じ表 |
| プロフ・固定ポストの改善 | 案を2つ作る → あなたが画面で直す（API に変更の入口が無い） | 同じ |
| DM への誘導文 | 締めの一文と返事の下書き（自動では送らない） | 同じ |

**費用は、あなたが使う AI エージェントの利用料と、あなたが取る X API の利用料だけです。** このキットがほかのサーバーにつないだり、お金を払わせたりすることはありません。
X API を使わずに「下書き＋あなたが貼る」だけで使うこともできます（その場合 X の費用は0円）。

**道具はどれも、`--go` を付けないと X に1回もつなぎません。** 何をいくらで呼ぶかの見積もりだけ出して止まります。

## 最初の10分

### 1. 動くか確かめる（2分・キーもお金も要りません）
Python 3.11 以上が入っていれば、追加の部品は要りません。
```bash
git clone <このリポジトリ> x-agent-kit && cd x-agent-kit
python3 scripts/analyze_patterns.py samples/sample_search.json   # 見本の投稿から型を数える
python3 scripts/review.py samples/sample_metrics.json             # 見本の数字で振り返りの表を作る
python3 scripts/research.py "AI 副業 -is:retweet lang:ja"          # 検索の見積もり（つながない）
```
見本はすべて架空のデータです。結果は `data/` にできます。

### 2. 自分のアカウントの設定を書く（3分）
```bash
cp config/account.example.md config/account.md
```
ジャンル・読者・投稿の時刻・「1週間に API に使ってよい額」を埋めます。分からない所は空のままで、エージェントに「一緒に埋めて」と頼んでください。

### 3. エージェントに渡す（1分）
このフォルダで AI エージェントを起動し、こう伝えます。
> AGENT.md を読んで、今週の企画表と最初のツリーの下書きを作って

Claude Code なら `CLAUDE.md` から自動で `AGENT.md` を読みます。

### 4. X API を使うなら キーを入れる（4分・使わないなら飛ばす）
```bash
cp .env.example .env
```
下の「キーの取り方」で取った値を `.env` に入れます。`.env` は誰にも渡さず、git にも入れません（`.gitignore` 済み）。
接続先（`X_API_BASE`）は空のままで構いません。公式ドキュメント https://docs.x.com/x-api/introduction の接続先が変わったときだけ、そこに書いてある値を入れてください。

## キーの取り方（X API）

1. https://developer.x.com でデベロッパー登録をする（X のアカウントでログイン）
2. 開発者コンソール（console.x.com）でアプリを1つ作る
3. アプリの「ユーザー認証の設定」で、権限を **Read and write** にする
4. キーを作り、`.env` に入れる
   - Bearer Token → `X_BEARER_TOKEN`
   - API Key / API Key Secret → `X_API_KEY` / `X_API_SECRET`
   - Access Token / Access Token Secret（自分のアカウント用）→ `X_ACCESS_TOKEN` / `X_ACCESS_TOKEN_SECRET`
   - 権限を変えたあとは Access Token を作り直す（古いものは読み取りだけのまま）
5. コンソールでクレジットを買い、**使いすぎ防止の上限**を決める
6. `.env` の `X_USERNAME` に自分のユーザー名（@ なし）を書く

画面の名前は X の都合で変わることがあります。迷ったら https://docs.x.com/x-api/getting-started/about-x-api を見てください。

## 費用（2026-10-27 時点・変わることがあります）

いまの X API は月額ではなく、**使った分だけ払う形**（先にクレジットを買う）です。

| やること | 目安 |
|---|---|
| 投稿1件 | 約0.015ドル |
| URL を含む投稿1件 | 約0.20ドル（URL なしの約13倍） |
| 他の人の投稿を1件読む（リサーチ） | 約0.005ドル |
| 自分の投稿・自分宛てを1件読む（振り返り） | 約0.001ドル |

例：毎日2本投稿＋週1回50件のリサーチ＋週1回の振り返り ≒ 1か月 約2〜3ドル（URL なし・ツリーは本数分かかる）。
正しい額と残高は開発者コンソールで見てください。

## できないこと（正直に）

くわしくは `docs/x-api-facts.md`（公式ドキュメントの出どころつき）。

- **引用投稿は API では作れません**（Enterprise 契約だけ）。下書きを作り、あなたが画面で引用して貼ります
- **他の人への返信は、相手があなたを @ で呼んだ投稿（またはあなたの投稿を引用した投稿）にだけ** API で送れます。それ以外は下書きを作り、あなたが貼ります
- **ツリー**は「自分の投稿への返信」でつなぎます。これが上の制限にかかるかは公式ドキュメントに書いてありません。2本目で断られたら、道具は止まって残りを「手で貼る分」に出します
- **予約投稿の入口は API にありません**。手元の予約表から時刻に出す（PC かサーバーを動かしておく）か、X の画面の予約にあなたが貼ります
- **プロフ文・固定ポストを変える入口は API にありません**。案を作るので、あなたが画面で直します
- **プロフへのアクセス数・リンクのクリック数**は、自分の投稿の **投稿から30日以内** しか取れません
- **検索は直近7日だけ**、1回100件まで
- **自動のフォロー・いいね・DM 送信は入れていません**（X の規約違反になりやすいため）
- X の料金と決まりは変わります。動かなくなったら `docs/x-api-facts.md` の出どころを開いて確かめてください

## 中身

```
AGENT.md            エージェントへの指示書（役割・毎日／毎週やること・判断の基準・やってはいけないこと・止まったとき）
CLAUDE.md           Claude Code 向け（AGENT.md を読むように1行）
playbooks/          作業ごとの手順（01 リサーチ 〜 07 DM 誘導）
templates/          ツリー3種・単発・引用・返信・プロフ・固定ポスト・DM 誘導・企画表・手で書く表2つ
scripts/            道具（標準ライブラリだけ・--go を付けたときだけ X につなぐ）
  thread_check.py     下書きの検査（文字数・1本目の長さ・締め・URL・禁止の言い回し）
  paste.py            検査が通った下書きを、手で貼る形で出す
  research.py         検索・参考アカウントの投稿・自分のプロフを読む（API）
  metrics.py          自分の投稿の数字・自分宛てを読む（API）
  post.py             単発・ツリー・自分宛てへの返事を投稿する（API）
  schedule.py         手元の予約表（時刻が来たら post.py で出す）
  import_manual.py    画面で見た投稿・数字を、道具が読める形にする（API なし）
  analyze_patterns.py 集めた投稿から伸びている型を数える
  review.py           自分の数字を表にして、次の企画の仮説を出す
  xlib.py / textutil.py 共通部品
config/             アカウントの設定の見本・禁止の言い回し
docs/x-api-facts.md X API でできること・できないこと（公式の出どころつき）
samples/            動作確認用の架空データ
```

## 予約を自動で動かす（任意）

`schedule.py run --go` を5分おきに動かします。Mac / Linux なら crontab に1行（パスは自分の場所に）：
```
*/5 * * * * cd /path/to/x-agent-kit && /usr/bin/python3 scripts/schedule.py run --go >> data/schedule.log 2>&1
```
PC が眠っていると動きません。予定から60分を過ぎた分は出さずに `queue/late/` へよけます。投稿に失敗した分は二重に出さないよう `queue/failed/` へよけます。

## このキットは N-Hack のAIエージェント専用です

このキットは N-Hack の受講生さん専用のプレゼントです。**N-Hack のAIエージェント
（N-Hack のプラグインを入れた Claude Code など）が、このパソコンで動いていること**を
前提にしています。

- どのスクリプトも、最初に `scripts/nhack_gate.py`（門）を通ります。門は、このパソコンに
  N-Hack のAIエージェントの「印」があるかを**読むだけ**で確かめます（ネットにつなぎません・
  何も書き換えません・プラグインには一切触れません）。
- 印が足りない環境では、スクリプトは動かずに止まります（終了コード 2）。この環境でだけ
  動くのが正しい姿です。
- いま N-Hack 環境かどうかは、次のコマンドで確かめられます。

```bash
python3 scripts/nhack_gate.py
```

N-Hack 以外のパソコンにコピーしても動きません。受講生ページ・コンサルチャンネルの案内に
沿ってご利用ください。

## 困ったとき・もっと伸ばしたいとき

分からない・動かない・時間がかかっている——そんなときは、ひとりで抱えないでください。
**N-Hack の受講生ページ／個別コンサルチャンネル**から、担当にそのまま相談できます。
あなた専用のAIと伴走しながら、最短で結果まで一緒に持っていきます。

このキットのAIは、あなたが詰まったときや区切りのときに、自分から相談先を案内します。
