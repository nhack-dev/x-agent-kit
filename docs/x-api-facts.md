# X API でできること・できないこと（2026-10-27 に公式ドキュメントで確認）

このキットは、ここに書いた事実をもとに作っています。X の料金と決まりはよく変わります。
**使い始める前と、うまく動かないときは、必ず公式ドキュメントと開発者コンソールで確かめてください。**

## 料金の形

- いまの X API は **使った分だけ払う形（プリペイドのクレジット）** です。月額の段（Free / Basic / Pro）の説明は、いまの公式ドキュメントにはありません。
  - 出どころ：https://docs.x.com/x-api/getting-started/about-x-api ／ https://docs.x.com/x-api/getting-started/pricing
- 開発者コンソール（console.x.com）でクレジットを買い、呼んだ分だけ減ります。1か月の使いすぎ防止の上限も決められます。
- 月に 300万件より多く読む場合は Enterprise（個別契約）です。
- 2026-10-27 時点の目安（**変わることがあります**）

| やること | 目安 |
|---|---|
| 投稿1件 | 0.015 ドル |
| URL を含む投稿1件 | **0.200 ドル**（URL なしの約13倍） |
| 他の人の投稿を1件読む（検索など） | 0.005 ドル |
| 自分の投稿・自分宛てを1件読む | 0.001 ドル |
| DM を1通送る | 0.015 ドル |

- 同じ日（UTC）に同じ投稿を2回読んでも、1回分です。
- 古い契約（Free / Basic など）を持っている方は、コンソールに出ている自分の契約の条件が優先です。

## 機能ごとの可否

| 機能 | API でできるか | このキットでの扱い |
|---|---|---|
| 単発の投稿 | ✅ できる（POST /2/tweets） | `post.py --go` で投稿（API なしは `paste.py` で貼る） |
| ツリー（自分の投稿に続ける） | 🟡 たぶんできる。ただし下の「返信の制限」が自分の投稿にもかかるかは、ドキュメントに書いていない | `post.py --go` が1本前への返信でつなぐ。2本目で断られたら残りを `drafts/manual/` に出して止まる |
| 他の人への返信 | 🔴 使った分だけ払う形では、**相手があなたを @ で呼んだか、あなたの投稿を引用したときだけ** | 自分宛ての @ への返事は `post.py`（type: reply）で送れる。それ以外は下書き → 持ち主が貼る |
| 引用投稿（quote_tweet_id） | 🔴 **Enterprise だけ**（使った分だけ払う形では不可） | 下書き → 持ち主が貼る |
| 予約投稿 | 🔴 予約の項目は API に**無い** | 手元の予約表（`schedule.py run --go` を5分おき）／または X の画面の予約に持ち主が貼る |
| 検索（直近7日） | ✅ できる（GET /2/tweets/search/recent・1回最大100件） | `research.py --go`（API なしは `import_manual.py research`） |
| 自分の投稿の数字（表示・いいね・リポスト・返信・引用・保存） | ✅ できる（public_metrics） | `metrics.py --go`（API なしは `import_manual.py metrics`） |
| プロフへのアクセス・リンクのクリック | ✅ できる（non_public_metrics の user_profile_clicks・url_link_clicks）。**自分の投稿だけ・投稿から30日以内だけ・自分としてのログイン（OAuth）が要る** | `metrics.py --go`（30日より前は取らない） |
| プロフ文・固定ポストの変更 | 🔴 API に変更の入口は**見つからない** | 案 → 持ち主が画面で直す |
| DM を送る | ✅ できるが、相手の DM 設定で届かないことがある・15分に15通／1日1440通まで | **自動で送らない**。誘導文と返事の下書きだけ作る |
| フォロー・いいねの自動化 | 技術的にはあるが、規約違反になりやすい | **入れていない** |

出どころ
- 投稿の作り方・返信の制限：https://docs.x.com/x-api/posts/manage-tweets/integrate
- POST /2/tweets の項目（予約の項目なし・引用は Enterprise）：https://docs.x.com/x-api/posts/create-post
- 数字の種類と30日の決まり：https://docs.x.com/x-api/fundamentals/metrics
- 回数の上限：https://docs.x.com/x-api/fundamentals/rate-limits
- DM：https://docs.x.com/x-api/direct-messages/manage/integrate

## 回数の上限（1ユーザーあたり・15分ごと）

| 入口 | 上限 |
|---|---|
| 投稿する（POST /2/tweets） | 100回（ドキュメント内に200回と書いた場所もある。コンソールの表示が正しい） |
| 投稿を読む（GET /2/tweets） | 5,000回 |
| 自分の投稿一覧（GET /2/users/:id/tweets） | 900回 |
| 検索（GET /2/tweets/search/recent） | 300回 |

## ドキュメントで決着しなかったこと（自分で試して確かめる）

1. 自分の投稿への返信（ツリー）が、返信の制限にかかるか → `post.py` は2本目で断られたら止まり、残りを手で貼る分に出します
2. 投稿の上限が15分100回か200回か → コンソールで確かめる
