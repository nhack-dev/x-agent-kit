# 04 投稿の予約

X API に予約の入口はありません。予約は2通りで行います。

## A. 手元の予約表で投稿する（API キーが要る）
1. 下書きの先頭に時刻を書く（タイムゾーンまで）
   ```
   ---
   type: tree
   at: 2026-11-01T19:00+09:00
   ---
   ```
2. 予約表に入れる（下書きを queue/ へ写すだけ・検査も通る・お金はかからない）
   ```
   python3 scripts/schedule.py add drafts/<そのファイル>.md
   python3 scripts/schedule.py list
   ```
3. 時刻が来た分を投稿する
   ```
   python3 scripts/schedule.py run          # 何が出るかだけ見る
   python3 scripts/schedule.py run --go     # 本当に出す
   ```
   これを5分おきに動かす（README の「予約を自動で動かす」）。PC が眠っていると動かない
4. 出したものは `queue/done/`、60分以上遅れた分は出さずに `queue/late/`、失敗した分は二重に出さないよう `queue/failed/` へ移る
5. 予約をやめるときは `python3 scripts/schedule.py remove <ファイル名>`

## B. X の画面の予約機能を使う（API キーが要らない）
1. 時刻つきの下書きを作り、`thread_check.py` で検査する
2. `python3 scripts/paste.py drafts/<ファイル>.md` の出力（先頭に【予約する時刻】）を1週間分まとめて持ち主に渡す
3. 持ち主が X の投稿画面で本文を貼り、予約のボタンで時刻を入れる（ツリーは「＋」で2本目以降を足す）
4. 予約し終えたら一言もらい、`data/posted.md` に「予約済み」と書く

## 時刻の決め方
- 最初の2週間は、企画表の時刻（朝・昼・夜の3つ）を回して、表示の差を数える
- そのあとは、振り返りで表示とプロフ率が高い時間帯に寄せる
- 決めた時刻は守る（遅れると表示が落ちやすい）
