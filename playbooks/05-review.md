# 05 数字の振り返りと、次の企画への反映

## いつ
- 毎週1回（例：日曜の夜）
- 投稿から24時間後に、その1本だけ軽く見る（任意）

## 手順
1. 数字を集める
   - API あり：自分の投稿の数字を読む（自分のデータなので1件約0.001ドル）
     ```
     python3 scripts/metrics.py --days 7          # 見積もり
     python3 scripts/metrics.py --days 7 --go     # 読む → data/metrics/<日付>.json
     ```
     表示・いいね・リポスト・返信・引用・保存はいつでも取れる。プロフへのアクセス・リンクのクリックは**投稿から30日以内**だけ
   - API なし：`data/posted.md` から先週の投稿を拾い、`templates/metrics-manual.csv` の形で行（URL・日付・種類・型・テーマ・1行目）をあなたが埋め、
     持ち主に各投稿の「アナリティクス」画面の数字だけ書いてもらう（ツリーは1本目だけ）→ `python3 scripts/import_manual.py metrics data/metrics-manual-<日付>.csv`
2. 表にする
   ```
   python3 scripts/review.py
   ```
   → `data/reviews/<日付>.md`
3. 表を読み、`data/learnings.md` に次の形で足す（消さずに上に足していく）
   ```
   ## 2026-11-08 の週
   - 当たり：（何の型が・どの数字で勝ったか・本数）
   - 外れ：（何が負けたか）
   - 次に確かめること：（1つだけ。例「体験の型を夜に2本出して、保存率が0.5%を超えるか」）
   ```
4. 来週の企画表を作る（`templates/kikaku.md` を `data/plans/<週>.md` へ）
   - 勝っている型を5本
   - 新しい型・時刻を1本だけ試す
   - 1本ずつ「何を確かめるか」を根拠の欄に書く

## 見る数字
| 数字 | 割り算 | 何が分かるか |
|---|---|---|
| 保存率 | 保存 ÷ 表示 | 後で見返したいほど役に立つか |
| プロフ率 | プロフへのアクセス ÷ 表示 | あなたに興味を持ったか（フォローの手前） |
| いいね率 | いいね ÷ 表示 | 共感されたか |

## 決まり
- 本数が3本未満の型は判断しない
- 数字が良かった理由を「たぶん」で書かない。比べた2本の違いを1つだけ書く
- 外れた試しも消さずに残す（次に同じ試しをしないため）
