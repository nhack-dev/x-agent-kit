# 02 ツリー型ポストを作る

## 型（templates/tree-*.md）
- `tree-howto.md` … 手順（数字で約束 → 1本1手順 → まとめ → 保存を頼む）
- `tree-story.md` … 体験（意外な結果 → 前の状態 → やったこと → 結果 → 最小の1歩）
- `tree-list.md` … 一覧（数と対象を約束 → 1本1項目 → 1つ選ばせる）

## 手順
1. 今週の企画表（`data/plans/<週>.md`）から1本選ぶ
2. 型をコピーして `drafts/<日付>-<短い名前>.md` を作り、（ ）を全部埋める
3. 検査する
   ```
   python3 scripts/thread_check.py drafts/<そのファイル>.md
   ```
   🔴 が0件、🟡 は理由があれば残してよい
4. 人に見せる（下書きのパスと、1本目だけを短く伝える）
5. OK が出たら
   - API あり：今すぐなら `python3 scripts/post.py drafts/<そのファイル>.md` で見積もり → `--go`／予約なら 04
   - API なし：`python3 scripts/paste.py drafts/<そのファイル>.md` で貼る形にして渡す
   - ツリーの2本目で断られたら（返信の制限）、残りは `drafts/manual/` に出る。持ち主に手で返信してもらう

## 書くときの決まり
- 1本目は 140（全角70字）以内。結果と数字だけ。中身はリプへ
- 1本に言うことは1つ
- 2本目以降の最初の行は見出し（①・1.・「最初の状態」など）
- URL は最後の1本だけ（または入れずにプロフへ）
- 最後の1本で頼むことは1つだけ（保存／プロフ／固定ポスト／フォローのどれか）
- 本数は 3〜7本。長くなったら2つのツリーに分ける

## 型を変えたいとき
振り返り（06）で、どの型が保存率・プロフ率で勝っているかを見てから変える。思いつきで変えない。
