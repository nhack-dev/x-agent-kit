# 06 プロフ・固定ポストの改善

プロフ文と固定ポストを変える入口は API にありません。エージェントは案を作り、持ち主が画面で直します。

## いつ
- 最初の1回
- 月に1回（振り返りで「プロフ率は高いのにフォローが増えない」とき）

## 手順
1. 今のプロフ文と固定ポストを読む（API あり：`python3 scripts/research.py --me --go`／なし：持ち主に貼ってもらう）
2. `templates/profile.md` で案を2つ作る（A：実績を前に／B：読者の悩みを前に）
3. `templates/pinned.md` で固定ポストの案を作る（ツリー・3〜4本）
4. 人に A・B を見せて1つ選んでもらう
5. 人が画面でプロフを直す
6. 固定ポストは `post.py --go`（API なしは `paste.py` で持ち主が投稿）→ 持ち主が「プロフに固定する」を押す
7. 変えた日を `data/learnings.md` に書く（その後2週間のプロフ率とフォローの増え方を前と比べる）

## 見るところ
- 名前の欄で「何の人か」が分かるか
- 自己紹介の1行目が、読者の得になる言葉で始まっているか
- 数字が1つ以上あるか
- 固定ポスト・プロフ・リンク先で、言っていることがそろっているか
